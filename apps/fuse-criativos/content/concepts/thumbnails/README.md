# Miniaturas de conceitos

Cada arquivo SVG nesta pasta é um placeholder substituível. Ao aprovar as imagens finais, preserve exatamente o nome-base do arquivo e substitua o SVG por `nome-base.png`, `nome-base.webp` ou outro formato que o catálogo passar a referenciar.

Os primeiros doze arquivos cobrem o mínimo de aceitação do MVP. Eles não devem ser apresentados como peças finais de campanha.
